## New Features

- Clean All Stale now asks whether to include active-module leftovers, and a failed delete no longer stops the run. Failures show a partial warning with a count.
- Unregistered settings of active modules now show a Leftover status instead of Pending, and the How To tab documents it. Pending is kept for system and core settings only.

## Bug Fixes

- Players no longer see the Clean All footer buttons, and Clean Module, Clean All and Clean All Stale now do nothing for non-GM users.
