## Bug Fixes

- Clean All Orphaned appears when the only orphaned data is user-scoped.
- Compendiums are re-locked even when a flag removal fails.
- Long setting values wrap instead of widening the table.
- Removing a single document's flag clears it from the compendium index.
- Stale and document counts in group headers are localized.
- The cleanup progress bar advances past missing compendiums and documents.
- The confirmation dialog for removing a single document's flag shows the document name instead of its UUID.
- The Settings tab sorts namespaces by status like the Overview.
- The This Browser group no longer lists localStorage keys that are not module settings.
