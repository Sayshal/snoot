## Bug Fixes

- Names and keys in confirmation dialogs no longer break onto separate lines.
- World and user flag scans read only saved flag data. Flags that other modules add in memory are never saved and cannot be removed, so they are no longer listed.

## Changes

- Bulk cleaning writes changes in batches and loads compendium documents in groups. A failed batch is retried one item at a time. The progress bar advances per item.
- Snoot is tested on dnd5e 6.1.
